Privacy Policy

Unscripted Worlds Uploader · Effective 2026-10-17

Unscripted Worlds Uploader ("the uploader") is a personal tool operated by Victor Bastos ("I") to publish videos to the Unscripted Worlds YouTube channel. It runs only on my own computer and is used only with my own Google and TikTok accounts. This policy explains exactly what Google user data it accesses, how that data is used, where it is stored, and how access can be revoked.

1. YouTube API Services

The uploader uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

2. Google user data accessed

Permission (scope)Why it is requestedWhat is actually used
https://www.googleapis.com/auth/youtube.uploadTo upload videos to the Unscripted Worlds channel.Sends a video file plus its title, description, tags, category and privacy status. Reads back the new video's ID to save its link.
https://www.googleapis.com/auth/youtube.readonlyTo confirm the uploader is connected to the correct channel before posting.Reads the channel's title only (channels.list, part=snippet, mine=true).

The uploader does not access Gmail, Drive, contacts, comments, subscribers, analytics, watch history or any other Google data, and it does not request the user's name, email address or profile.

2b. TikTok user data accessed

Permission (scope)Why it is requestedWhat is actually used
user.info.basicTo confirm the uploader is connected to the correct TikTok account.Reads the account's open ID and display name only.
video.uploadTo send a finished video to the account's TikTok inbox as a draft, which I then finish and post in the TikTok app.Sends a video file. Reads back the upload's status.
video.publishTo post a finished video directly to the Unscripted Worlds TikTok account.Sends a video file, caption and privacy setting. Reads back the post's status.

The uploader does not access followers, following lists, messages, comments, likes, analytics or any other TikTok data. TikTok's handling of data is described in the TikTok Privacy Policy.

3. How the data is used

  • Only to upload videos I created and to confirm the destination channel or account.
  • Uploads happen only when I run the publish command for a specific video. Nothing is posted automatically on a schedule.
  • Google and TikTok user data is not sold, not shared with or transferred to any third party, not used for advertising, and not used to develop, improve or train any artificial-intelligence or machine-learning model.
  • The uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Storage and security

  • Refresh tokens and app credentials (Google and TikTok) are stored in one file on my own computer (~/.config/ai-civilization/publish.json), readable only by my user account (file permission 600). This file is kept outside the project's source code and is never committed to Git or uploaded anywhere.
  • Access tokens are short-lived, kept only in memory while an upload runs, and never written to disk.
  • Channel/account names, video IDs, upload status and links returned by YouTube or TikTok are saved in local project files that record what was published.
  • There is no server, database or cloud storage operated by the uploader. All requests go directly from my computer to Google or TikTok over HTTPS.

5. Retention and deletion

The refresh token is kept until access is revoked or I delete the credentials file. Deleting ~/.config/ai-civilization/publish.json removes all stored Google credentials from the uploader immediately. Records of published video links are kept as part of my project files; the videos themselves are managed in YouTube Studio.

6. Revoking access

Access can be revoked at any time from the Google Account security settings at https://security.google.com/settings/security/permissions (also at myaccount.google.com/permissions). After revocation the stored refresh token stops working and the uploader can no longer access the account.

6b. Revoking TikTok access

In the TikTok app: Profile → Menu → Settings and privacy → Security and permissions (or Apps and services) → Manage app permissions → remove Unscripted Worlds Uploader. Deleting the local credentials file also removes the stored TikTok tokens immediately.

7. This website

This site is static, hosted on GitHub Pages, sets no cookies and uses no analytics or tracking. GitHub may log technical request data as described in the GitHub Privacy Statement.
